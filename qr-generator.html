How to make a QR code

  1. Enter a website address or short text in the box.
  2. Choose a size and colour, then select Generate QR code.
  3. Download the PNG and scan it with your phone to test it.

What can a QR code be used for?

QR codes can make it easier to open a website, share an event link, display a digital menu, or provide short instructions. The code stores the text you enter, so anyone who scans it may be able to read that content. Use a trusted destination and test the code before printing it.
