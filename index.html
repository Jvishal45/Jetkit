QUICK GUIDE

Which tool should you use?

QR Code Generator

Use it to share a website, menu, event page, Wi-Fi instructions, or a short text. Test the downloaded code with your phone before printing or publishing it.

Image Compressor

Use compression when a website upload has a file-size limit or when you want a lighter image. Compression can affect image quality, so compare the preview before downloading.

Image Resizer

Use resizing when a platform requests specific dimensions. Keep the aspect ratio when you want to avoid stretching or squashing the original image.
