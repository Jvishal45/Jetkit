When should you resize an image?

Resize images to match a website, social post, form, or presentation's pixel dimensions. If you keep the aspect ratio, the tool adjusts the other dimension to reduce stretching. If you turn it off, the output can look distorted.

Image dimensions and quality

Changing pixel dimensions changes the number of pixels in the output. Enlarging a small image cannot recreate detail that was not in the original. Check the preview before using your resized file.
